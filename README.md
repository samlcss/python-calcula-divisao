# ➗ Calculadora de Divisão com Tratamento de Erros

Programa iniciante em Python para realizar a divisão entre dois números, aplicando boas práticas de tratamento de exceções com blocos `try/except`.

## 📌 Conceitos Praticados
- Entrada de dados pelo usuário (`input`) convertida para `float`.
- Operações matemáticas (divisão `/`).
- Tratamento de exceções:
  - `ValueError`: caso o usuário digite texto em vez de número.
  - `ZeroDivisionError`: caso o usuário tente dividir por zero.

## 🚀 Como Executar

```bash
python calcula_divisao.py
```

## 💻 Exemplo de Saída
```text
* * * CALCULADORA DE DIVISÃO * * *

Entre com o primeiro número: 10
Entre com o segundo número: 2
O resultado é: 5.0
```
